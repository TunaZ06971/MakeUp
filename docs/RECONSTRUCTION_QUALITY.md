# 几何与妆容质量边界

当前 Web 仍使用粗略脸部几何。连续采集改善的是输入保存与用户操作，不是已经更换为高精度整头模型。

已实现的外观处理包括共享顶点的连续纹理混合、曝光匹配、后台烘焙、原图对照，以及分开的外观颜色和涂层光泽。它们可以改善接缝和显示，但不增加个人头发、耳朵或未观察到的几何。

TrueDepth 实验仅使用可靠的可见深度；它不保证发丝、耳内褶皱或后脑覆盖，也未完成真实用户的精度标定。原始深度失败不会以粗模板冒充实测。

妆容材质目前是视觉近似。照片中的光照尚未完全分离，品牌色号、皮肤散射和镜面响应未经受控实拍校准。不要把产品预设当作购买色号或实物妆效的准确预测。

质量验收应比较同一输入、相同角度与光照下的几何、纹理和妆容，并保留失败案例。真人对照必须留在私人测试空间。更多目标见 [重建研究方向](RECONSTRUCTION.md)，自动化限制见 [测试指南](TESTING.md)。
